# LSTM Practice Questions

## 📌 About 
This repository contains an assignment on **Long Short-Term Memory (LSTM) Networks**, a type of Recurrent Neural Network (RNN) used to learn patterns and long-term dependencies in sequential data.

The assignment focuses on understanding LSTM calculations, trainable parameters, gradient flow, and real-world applications of LSTM networks.

## 🎯 Objectives
- Understand the working of an LSTM cell.
- Calculate the number of trainable parameters in an LSTM layer.
- Understand the vanishing gradient problem and the role of forget gates.
- Apply LSTM concepts to electricity load forecasting.
- Explore predictive maintenance using failure prediction and evaluation metrics.

## 📚 Topics Covered

### 1. LSTM Forward Pass
Calculate the forget gate, input gate, candidate cell state, updated cell state, output gate, and hidden state.

### 2. LSTM Parameter Count
Calculate the number of trainable parameters in an LSTM layer under different bias conventions.

### 3. Vanishing Gradient
Analyze how forget-gate values affect gradient flow over long sequences and how LSTMs help learn long-term dependencies.

### 4. Electricity Load Forecasting
Explore the use of LSTM networks to predict future electricity demand using historical load, temperature, and holiday information.

### 5. Predictive Maintenance
Apply min-max normalization, classify equipment failure using a probability threshold, and calculate precision, recall, F1-score, and accuracy.

## 🛠️ Concepts and Formulas
- **Sigmoid Activation:** Used to control information flow through the gates.
- **Tanh Activation:** Used to generate candidate cell-state values.
- **Min-Max Normalization:** Used to scale numerical data.
- **Evaluation Metrics:** Precision, recall, F1-score, and accuracy.
- **Sequence Modeling:** Learning patterns from time-series data.
